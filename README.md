# Tab Manager

> 让您的浏览器标签管理进入工程师级别的掌控。

一个基于 Manifest V3 的高性能的 Chrome 标签管理扩展程序。

## 🚀 极速引导 (Quick Start)

所有开发生命周期指令已完全闭环收敛至 `Makefile` 任务编排中枢。

```sh
# 安装所有环境依赖
make setup

# 激活支持 HMR 的 Vite 调试层
make dev

# 查阅全量工程执行流手册
make help
```
